# STM32F407ZGT6 麦克纳姆底盘（V1.4 阶段1整理）

本工程从桌面 `407-2` 的可驱动电机工程复制 HAL、CAN1 和 Keil 配置，保留其已验证的 X42S CAN 协议实现。新应用代码位于 `User/`。

## 硬件与约定

- CAN1：PA11 RX、PA12 TX，500 kbit/s（APB1=42 MHz，Prescaler=14，1+4+1 TQ）。
- M1/M2/M3/M4 地址默认是 1/2/3/4。
- 轮径 103 mm，前后轮心距 213 mm，左右轮心距 258 mm。
- x 正方向为前进，y 正方向为向左横移，角度正方向为俯视逆时针。
- M1/M3 安装方向取反，沿用参考工程；首次架空测试必须确认。

## 首次测试

1. 将四轮架空并确认急停条件。
2. 打开 `MDK-ARM/STM32F407_CAN_CMD.uvprojx`，编译并烧录。
3. 当前按下启动按钮后，Mission固定执行一次 X 方向 1000 mm 直线测试。
4. 若单轮方向错误，只修改 `User/config/chassis_config.h` 中对应的 `MOTOR_Mx_SIGN`。

## 重要说明

长距离动作采用“EMM42速度模式运行 + 0x36位置反馈距离判断”。`trajectory`模块生成速度指令，其中当前1000 mm测试使用梯形速度规划；距离不足时保留三角形兼容分支。四轮位置增量按每圈65536个反馈单位换算为轮面距离，达到目标后停止。X42S CAN协议只接受0~255的加速度档位，因此通过`MOTOR_ACCEL_MM_S2_PER_LEVEL`进行映射。

接口调用示例：

```c
Chassis_MoveX(1000.0f, 700.0f);
```
